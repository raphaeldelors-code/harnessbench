Methodology

  • Fixed model, variable harness. One local model (Strata Qwen3.8-Flash-Next IQ3_S served by llama-swap, exclusive GPU) is driven by 11 coding-agent harnesses. Only the agent scaffolding changes.
  • Shared task statement. Every harness receives byte-identical task text; harness-native system prompts otherwise untouched.
  • Official grading. Captured patches are re-applied and graded inside official SWE-bench eval containers (fail-to-pass + pass-to-pass tests), in isolation, with exact test logs.
  • Deterministic dataset. A fixed instance subset per cohort; cohorts with the same subset are directly comparable (see cohort map).
  • Significance. Pairwise exact two-sided McNemar on discordant resolved counts (heat map in each run).
  • Telemetry. Per-instance wall windows and llama-swap token counters (input / output / cache) recorded for every attempt.
  • Reproducible. Each run stores an run.json manifest + exact component versions; raw preds are gzip-persisted.
  • Two bench lanes, never mixed. The Harness lane fixes the model and varies the agent. The Models lane fixes the agent layer and varies the engine (quantization / settings): legs compared inside one prompt-size cell on prefill and decode speed, verdict written by hand. Speed only — no task quality, and its tok/s are not comparable to resolved % or to another model.
  • Showdown rounds are a third thing. Inside the Models lane, an agentic round runs mini-swe-agent once over the 10 SWE-bench Verified instances on one served build and is graded by the official eval container: resolved / 10, partial credit from the fail-to-pass fraction, GPU-hours from the run log. It shares the lane's rig and serving stack but not its measurement — those rounds are shown on their own tab and enter no tuning median, cell or Δ.

Long version — including the model lane's noise-floor rule (median over ≥3 reps per cell) and what neither lane claims: docs/METHODOLOGY.md in the source repository.
