Methodology

  • Fixed model, variable harness. One local model (Strata Qwen3.8-Flash-Next IQ3_S served by llama-swap, exclusive GPU) is driven by 11 coding-agent harnesses. Only the agent scaffolding changes.
  • Shared task statement. Every harness receives byte-identical task text; harness-native system prompts otherwise untouched.
  • Official grading. Captured patches are re-applied and graded inside official SWE-bench eval containers (fail-to-pass + pass-to-pass tests), in isolation, with exact test logs.
  • Deterministic dataset. A fixed instance subset per cohort; cohorts with the same subset are directly comparable (see cohort map).
  • Significance. Pairwise exact two-sided McNemar on discordant resolved counts (heat map in each run).
  • Telemetry. Per-instance wall windows and llama-swap token counters (input / output / cache) recorded for every attempt.
  • Reproducible. Each run stores an run.json manifest + exact component versions; raw preds are gzip-persisted.
